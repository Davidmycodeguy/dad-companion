How the AI prices an item

The app reads the Marketplace listing by listing into a database on your PC and trains its price model there in a few seconds.

For every item it learns what each random roll adds in gold, and how pairs of rolls change the price. On Legendary Heavy Gauntlets, for example, Physical Power with Strength sells for about 17% more as a pair.

The card also shows where the item sits among live listings, so you never undercut your best rolls.

Get started

  1. Download DaD.Companion_x.y.z_x64-setup.exe from the latest release.
  2. Run it. If Windows says "Windows protected your PC", click More info then Run anyway.
  3. Install Npcap (free) so the app can follow your stash and listings.
  4. Start Dark and Darker, then DaD Companion. Market data is included, so values work right away.
